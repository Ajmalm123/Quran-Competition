# Lucky Draw – Winner Selection (frontend prototype)

React + TypeScript + Tailwind CSS + Framer Motion + Lucide + canvas-confetti.
Frontend only: no backend, API calls, database or auth. All data is local (`src/data.ts`).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

States: Ready -> Rolling -> Winner revealed -> Confirm modal -> Result published.
Use "Reset demo" (footer) or "Back to overview" to run it again.
